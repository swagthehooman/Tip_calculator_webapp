# Tip Calculator App

## Introduction
This is a [Frontend mentor challenge](https://www.frontendmentor.io/challenges/tip-calculator-app-ugJNGbJUX/hub). In this challenge, we have to create a tip calculator, where the user will be able to input total bill, tip percent and also the number of people. The webapp will calculate the total amount and also total tip amount.

## Tech stack
1) React.js
2) css
